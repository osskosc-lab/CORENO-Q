# Correlon-LX v0.2 experiment workspace

This directory preserves the preregistered execution boundary for Correlon-LX v0.2.

- `frozen/`: byte-level source manifest and repository-freeze inputs
- `src/`: repository-freeze audit implementation
- `tests/`: repository-freeze audit tests
- `artifacts/cycle1-run0/`: immutable record of the initial missing-input stop
- `artifacts/cycle0f/`: generated Repository Freeze decision and audit trail
- `artifacts/cycle1-run1/`: reserved for a fresh run only after Cycle 0F passes

No detector, adapter, residual stream, or synthetic evaluation data is reconstructed from summaries.
